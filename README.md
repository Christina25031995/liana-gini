# LIANA GINI — production site (deployment build)

Готовая к публикации статическая версия сайта. Файлы уже связаны относительными путями.

## Структура

```
dist/
  index.html                  десктопная главная
  mobile.html                 мобильная и планшетная версия (одна страница, все вкладки)
  hero.dc.html                первый экран
  section-02.dc.html ... section-10.dc.html   блоки страницы
  assets/js/
    support.js                рантайм компонентов (обязателен)
    image-slot.js             слот под видеовизитку в мобильной версии
    payments.js               реестр товаров и точки подключения оплаты
    enquiry.js                отправка формы заявки
  assets/media/               видео и фотографии
  assets/media/slots/         фотографии, вставленные в слоты
  .nojekyll                   отключает обработку Jekyll на GitHub Pages
```

Все имена файлов без пробелов и скобок — обязательное условие для GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите **содержимое папки `dist/`** в корень ветки (или в папку `/docs`).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` либо `/docs`.
3. Сайт откроется по адресу `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` обязателен — без него GitHub Pages может не отдать часть файлов.

## Десктоп и мобильная версия

`index.html` и `mobile.html` — две отдельные вёрстки. Переключение автоматическое:

- узкий экран или сенсорное устройство → `mobile.html`;
- широкий экран без сенсора → `index.html`.

Чтобы открыть конкретную версию принудительно (например, посмотреть десктоп с телефона),
добавьте к адресу `?nored`: `https://.../index.html?nored`.

Мобильная версия рассчитана на 360–768px и включает все вкладки: главная, каталог,
услуги, команда, кейсы, контакты.

## Локальная проверка

Открывать `index.html` двойным щелчком нельзя: браузер заблокирует загрузку блоков
через `file://`. Нужен локальный сервер:

```
cd dist
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Что требует подключения на бэкенде

Фронтенд готов, но эти точки пока не подключены к серверу:

- `assets/js/payments.js` — оплата товаров и консультации. Ключи и защищённые
  ссылки на файлы во фронтенде отсутствуют намеренно: доступ к материалам должен
  выдаваться только после подтверждения оплаты на сервере.
- `assets/js/enquiry.js` — отправка заявки из финальной формы в Telegram или на почту.
- Юридические страницы (политика, оферта, реквизиты) — ссылки в футере ведут на
  заглушки, реальные документы нужно добавить.

## Шрифты

Archivo подключается с Google Fonts. Для работы без внешних запросов шрифт нужно
положить локально и заменить `<link>` на `@font-face`.
